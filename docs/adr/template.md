# ADR NNNN — Short, imperative title

- **Status**: proposed | accepted | deprecated | rejected
- **Date**: YYYY-MM-DD
- **Deciders**: @handle1, @handle2
- **Supersedes**: (link to prior ADR, if any)
- **Superseded by**: (link to replacement, if any)

## Context

What problem are we solving? What constraints apply (team size, budget,
timeline, existing ecosystem)? What forces pull in different directions?

## Decision

The decision, stated in one short paragraph. Imperative, unambiguous.

## Alternatives considered

For each serious alternative, 2–4 lines: what it is, why it was rejected.

## Consequences

- **Positive** — what becomes easier / possible.
- **Negative** — what becomes harder, what we accept as cost.
- **Follow-ups** — explicit TODOs unlocked by this decision.
